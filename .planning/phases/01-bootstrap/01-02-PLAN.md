Key implementation rules — each prevents a silent Kodi failure:

1. **ZIP arcname MUST be explicit** (Pitfall 1):
   ```python
   rel = os.path.relpath(full_path, addon_src_dir)
   arcname = os.path.join(addon_id, rel)
   zf.write(full_path, arcname)
   ```
   Never use `zf.write(full_path)` without arcname — that preserves the full source path.

2. **addons.xml must be written with encoding='utf-8', newline='\n'** (Pitfall 3):
   ```python
   with open(path, 'w', encoding='utf-8', newline='\n') as f:
   ```
   NOT 'utf-8-sig' (adds BOM). NOT default newline (adds CRLF on Windows).

3. **Both checksum files MUST be written in the same function call as addons.xml** (Pitfall 2):
   Use `write_index_and_checksums()` which writes all three files atomically.

4. **ET.tostring must use encoding='unicode'** (not encoding='utf-8') to return a str without BOM or XML declaration:
   ```python
   ET.tostring(elem, encoding="unicode")
   ```

5. **Repo addon ZIP goes at staging root** (not inside repository.sandwichfarm/ subdir):
   After make_zip(), move the ZIP from output/repository.sandwichfarm/repository.sandwichfarm-1.0.0.zip to output/repository.sandwichfarm-1.0.0.zip.

6. **Assert no BOM before writing** in write_index_and_checksums():
   ```python
   xml_bytes = content.encode('utf-8')
   assert not xml_bytes.startswith(b'\xef\xbb\xbf'), 'BOM detected'
   ```
